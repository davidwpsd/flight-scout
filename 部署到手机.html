部署到手机（iPhone / 安卓都能用）

做完之后你会得到一个网址。iPhone 上用 Safari 打开 → 分享 → 添加到主屏幕，

桌面上就多了一个图标，点开是全屏的工具，和 App 用起来没区别。

同事也拿同一个链接，各自加主屏幕即可。

整个过程不用写代码，大约 10 分钟。

开始之前

  • 一个 GitHub 账号（免费注册：https://github.com/signup）
  • 你的 SerpApi key（就是之前填进设置框的那串）
  • 建议装一个 GitHub Desktop（https://desktop.github.com/），比网页上传省事很多

第 1 步：建一个仓库

  1. 打开 https://github.com/new
  2. Repository name 填 flight-scout
  3. 选 Public（重要，见下面的说明）
  4. 点 Create repository

为什么必须选 Public？

公开仓库的 GitHub Actions 是无限免费的；私有仓库每月只有 2000 分钟额度，而且 Pages 也要付费。

公开的只是代码，你的密钥不会出现在代码里（下一步会单独存到 Secrets）。

第 2 步：把文件传上去

方法 A：GitHub Desktop（推荐）

  1. 打开 GitHub Desktop → File → Clone repository → 选你刚建的 flight-scout
  2. 选一个本地位置（比如桌面），Clone
  3. 打开 Clone 下来的文件夹，把本地 flight-scout 文件夹里的所有内容复制进去
  4. 回到 GitHub Desktop，左下角填一句说明（比如 init），点 Commit to main
  5. 点右上角 Push origin

方法 B：网页上传

仓库首页 → Add file → Upload files → 把文件拖进去 → Commit changes。

⚠️ 两种方法都要注意：不要上传这些（有的话删掉再传）

不要上传原因
config.json里面是你的密钥
site/ 文件夹服务器会自动生成
__pycache__/缓存垃圾
.git 文件夹会把旧历史带进去

第 3 步：把密钥存进 Secrets

  1. 仓库页面 → Settings → 左侧 Secrets and variables → Actions
  2. 点 New repository secret
  3. Name 填：SERPAPI_KEY
  4. Secret 粘贴你的 key（前后不要有空格）
  5. Add secret

这里存的东西不会出现在代码、日志或网页里。这是唯一安全的放法。

第 4 步：开启 Pages

  1. Settings → 左侧 Pages
  2. Build and deployment → Source 选 GitHub Actions
  3. 不用点别的，保存即可

第 5 步：跑第一次

  1. 仓库页面 → Actions 标签
  2. 左侧看到 Update prices → 点进去 → 右边 Run workflow → 绿色按钮
  3. 等 1～2 分钟，两个任务变绿（build ✅ deploy ✅）
  4. 点 deploy 那一步，会看到一行网址：
https://你的用户名.github.io/flight-scout/

这就是你的工具地址。

如果第一次跑挂了：点进去看红色那一步的日志。最常见是两个原因——

① 忘了加 SERPAPI_KEY；② key 输了但多了空格。

第 6 步：加到 iPhone 主屏幕

  1. 必须用 Safari（Chrome 加到主屏幕会变成一个普通书签，不会全屏）
  2. 打开上面那个网址
  3. 点底部中间的 分享 按钮（方框带向上箭头）
  4. 往下滑，选 添加到主屏幕
  5. 名字可以改成「机票雷达」，点 添加

桌面上就有图标了。点开是全屏，没有地址栏。

分享给同事

把同一个网址发给对方，让他们用 Safari 打开、同样「添加到主屏幕」即可。

  • 对方不需要注册任何东西，也不需要 key
  • 他们看到的是每天更新的快照，不是实时价格
  • 他们点行尾的 Google / Trip 可以去核对当下价格

常见问题

Q：页面上写「快照更新于 10-21 07:00」，是实时的吗？

不是。GitHub 只有定时任务，没有常驻服务器，所以价格是上次抓取的结果。想查此刻价格，点行尾的 Google / Trip。

Q：额度够吗？

一次抓取约 5 次调用，一天一次 ≈ 150 次/月，免费额度 250 次/月，够用。别把 ORIGINS 加太多，每个城市都会多 5 次。

Q：三个月后突然不更新了？

GitHub 会自动停掉「长期无提交」仓库的定时任务。去 Actions 点一次 Run workflow 就恢复了。

Q：链接被别人转发了怎么办？

对方只能看到价格，拿不到你的密钥。但他们查询也会消耗你的额度。介意的话去 SerpApi 后台重置 key，再更新 Secret。

Q：能收降价推送吗？

目前不行。这需要常驻服务器 + 推送服务，iPhone 上还要 iOS 16.4 以上并装到主屏幕。以后想做可以加。

Q：为什么不用 App Store？

要 99 美元/年 + 一台 Mac + 每次审核等待，而且苹果对「网页套壳」的 App 基本会拒。这个工具用链接 + 主屏幕完全够。
